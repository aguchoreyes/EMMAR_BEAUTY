¿Te sale aviso de Reglas (Rules) o no encuentras dónde activarlas?

Haz clic en cualquiera de estos dos botones azules: te llevarán directamente a la pantalla exacta de tu proyecto en Google Firebase sin que tengas que buscar menús:

Si en esa ventana ves un botón que dice "Crear base de datos" (Create database):

1️⃣ Haz clic en "Crear base de datos" → elige "Comenzar en modo de prueba" (Start in test mode) → dale a Habilitar/Crear.
2️⃣ Si ya está creada, pega estas reglas públicas y dale al botón Publicar (Publish):

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }

Paso Único para dejar la Base de Datos Conectada Permanentemente en GitHub:

GitHub aloja un archivo estático. Para que la conexión a tu base de datos quede grabada permanentemente dentro de la web (y ningún cliente vea los productos antiguos de prueba), haz clic en "Copiar Código HTML con Base Conectada" y pégalo en tu archivo index.html de GitHub una sola vez.
